## 三个细节

### 1. 首页鲸鱼大幅缩小

- 首页「你好，今天想聊点什么？」上方的鲸鱼从 112dp 缩到 **60dp**。
- 位置和问候文字保持居中，不再压住整个页面。

### 2. 允许删除对话

历史抽屉新增删除模式：

- 点分组右侧的筛选图标进入选择模式；长按任意对话也可以直接进入并选中。
- 每行左侧出现圆形勾选；支持多选。
- 底部变为「已选 N 个 / 取消 / 删除」。
- 点删除弹出确认框，确认后删除选中对话，并取消正在运行的生成任务。
- 返回键先退出选择模式，不会误关抽屉。

### 3. APP Logo 加深色底 + 小字

- 桌面/启动图标改为：官方鲸鱼 Logo + 下方小字「无限制版」。
- 自适应图标前景用 432×432 透明 PNG，背景色 `#0F0F0F`；鲸鱼和文字都在自适应图标安全区内。
- 首页和启动页仍使用官方鲸鱼 Logo，不叠加小字。
