## 这版只改前端观感：去灰、去白边、换回正常鲸鱼

### 1. 去掉底部白边

- `MainActivity` 改为强制深色 edge-to-edge 系统栏，状态栏/导航栏透明、深色图标。
- `Theme.kt` 同时设置导航栏透明、关闭系统栏对比度强制、白色系统图标。
- `themes.xml` 增加深色 window background、透明状态栏/导航栏。
- 启动页背景统一为 `#0F0F0F`，避免启动/退出时闪白。

### 2. 首页鲸鱼换回正常版

- 0.9.5 首页用的是官方「额度受限」页面里的趴姿鲸鱼，搞错了。
- 现在首页换回官方鲸鱼 Logo（带白色腹部/眼白），和启动图标一致。
- 尺寸从 96dp 调到 112dp，位置更接近官方空对话页。

### 3. 去灰：整套暗色参数重做

之前看起来“蒙了灰”，主要原因是背景偏蓝灰、卡片是半透明叠色、正文不是纯白。现在：

- 背景：`#191A1D` → `#0F0F0F`（纯中性黑）。
- 卡片/输入框：`#232428` → `#242424`（实色，不再 alpha 叠加）。
- 设置页背景：`#1E1E1E`，设置卡片 `#2A2A2A`。
- 正文：`#F0F1F4` → `#FFFFFF`（纯白）。
- 次要文字：`#9A9DA6` → `#A6A6A6`（中性灰）。
- 分割线/描边：`#2F3138` → `#333333`。
- 用户气泡：从蓝紫 `primaryContainer` 改为中性 `#242424`，不再发灰蓝。
- 输入框、来源胶囊、思考块、工具块全部改实色，去掉 `copy(alpha=...)` 叠色。
- 操作图标从 `#A6A6A6` 提到 `#B3B3B3`，并加大到 24dp。
- 激活胶囊改为深蓝底 `#1F2B4D` + 亮蓝字 `#7C97FF`，不再用半透明蓝。
- 设置页改用官方式 `#1E1E1E` 背景 + `#2A2A2A` 卡片。

### 4. 其他 UI 参数

- 首页鲸鱼 112dp。
- 对话操作按钮 42dp 点击区、24dp 图标。
- 正文 18sp / 30sp 行高。
- 设置页行高、图标、圆形返回按钮、模型 footer 保持上一版并统一为中性色。

- 来源 favicon 仍是首字母色块。
