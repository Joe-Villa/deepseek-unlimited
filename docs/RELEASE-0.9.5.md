## 这版只做前端：把首页/对话/抽屉/组件再对齐官方

### 1. 首页改成官方「空对话」结构

- 去掉「DeepSeek」标题、去掉「新对话」大按钮、去掉「对话只存在这台手机」提示。
- 顶栏：左侧双线菜单，右侧朗读、圆形加号；中间没有标题。
- 中间：官方同款的**趴姿鲸鱼**（从官方截图提取、透明背景、白肚皮/眼白），下面是大号问候。
- 底部：和对话页同一套输入框，可以直接输入第一句话，发送后创建新对话。
- 底部提示改为官方式的「回答由 AI 生成，仅供参考」。

### 2. 输入框按官方重做

- 大圆角深色卡片，去掉边框；占位文案「发消息或按住说话」，18sp。
- 左上不再有加号；左下是「深度思考 / 智能搜索」两个带图标的蓝色胶囊。
- 右下按状态切换：
  - 空输入：圆形加号 + 语音波形；
  - 有文字：蓝色发送箭头 + 语音波形；
  - 生成中：圆形 X + 语音波形。
- 点加号不再弹普通菜单，而是官方式的底部面板，三个大按钮：拍照 / 相册 / 文件。
- 顶栏的加号换成描边圆形加号，不再用 Material 的实心圆。

### 3. 对话页更像官方

- 顶栏标题改为左对齐（不再居中），字号 18sp；左侧双线菜单，右侧朗读/加号。
- 正文字号提高到 18sp、行高 30sp，段落更接近官方的大字排版。
- 消息操作图标从 19dp 提到 22dp；补上官方动作条里的「朗读」，现在是复制/赞/踩/朗读/分享/重新生成。
- 联网搜索从一整块卡片改成官方同款的**胶囊**：
  - 搜索中：转圈 + 正在联网搜索…
  - 完成后：叠放的网站图标 + 「N 个网页」
  - 点击弹出「搜索结果」底部面板，逐条列出来源。
- 来源胶囊移到回答正文下方、操作按钮上方（之前在上面，位置错了）。

### 4. 历史抽屉

- 搜索框改成 56dp 高、24 圆角。
- 分组标题右侧加筛选/管理图标；行高加到 56dp，文字 17sp。
- 去掉当前会话的整行高亮，贴近官方。
- 底部改成「头像式圆形设置入口 + 设置 + …」，不再显示「无需登录」小字。

### 5. 设置页

- 去掉大块「本地存储」宣传卡。
- 按官方分组补上：应用（语言 / 外观 / 字体大小）、语音（朗读音色）、连接（API Key）、本机数据、关于（检查更新 / 服务协议 / 关于与免责声明）。
- 行高、图标、字号、圆形返回按钮、模型/免责声明 footer 对齐官方。
- 语言/外观/字体大小目前只做视觉与提示，不改变实际行为（聚焦前端）。

### 6. 鲸鱼

- 启动图标仍是官方鲸鱼 Logo（带白色腹部/眼白）。
- 首页换成官方截图里的趴姿鲸鱼，两者不是同一个姿势，和官方 App 的分工一致。

## 没做/仍不同

- 对话页菜单仍是回到首页展开抽屉，不是覆盖在对话上的抽屉。
- 选择对话多选页、分享面板的生成图片/微信等原生集成没有做。
- 联网来源的 favicon 用首字母色块代替，不是真实站点图标。
- 真机/模拟器未跑；本机无 KVM，也没有真实 Key。
- 版本仍是 debug 签名、约 59MB。
