和官方一致：

- 点左上角菜单打开历史抽屉时，先清除输入框焦点并隐藏输入法。
- 从聊天页菜单返回首页并自动打开抽屉时，同样收起键盘。
- 手势滑开抽屉时也生效（监听 drawerState.isOpen）。
- 不再出现键盘把抽屉/输入框顶起、挡住内容的情况。
